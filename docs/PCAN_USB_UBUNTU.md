# UbuntuでPCAN-USBを使う

以下はインターフェース`can0`、bitrate `500000 bit/s`の例です。CAN送信は接続先を動作させる可能性があるため、送信先とデータを確認したテスト環境で実行してください。

## セットアップ

```bash
ip -br link
sudo ./linux/setup-can.sh can0
```

`setup-can.sh`は`peak_usb`を読み込み、`can0`を500 kbit/sで有効化します。**これだけで常に完了するわけではありません。** PCAN-USBがドライバーに認識されて`can0`等が存在すること、実際のバスも同じbitrateであることが必要です。スクリプトはドライバーや追加ツールをインストールしません。インターフェース名が異なる場合は`can0`を置き換えてください。

CAN-H/CAN-Lの配線とバス両端の終端抵抗も確認してください。送信時は、フレームにACKを返す別のCANノードが必要です。

## CANデータを受信する

```bash
sudo apt install can-utils
sudo candump can0
```

`candump`を実行している間、バス上のCANフレームが表示されます。受信だけなら、別のノードからフレームが送信されている必要があります。受信コマンドは送信スクリプトとは別です。

## CANデータを送信する

別の端末から1フレーム送信します。IDは16進数、データは16進数のバイト列です。

```bash
sudo ./linux/send-can.sh can0 123 1122334455667788
```

この例は標準ID `0x123`、データ8バイトを1回送ります。`send-can.sh`は送信専用です。
